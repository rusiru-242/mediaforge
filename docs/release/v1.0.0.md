# MediaForge Release Notes — v1.0.0

**Release Tag:** `v1.0.0`  
**Release Date:** November 13, 2026  
**Status:** Production Release Candidate  
**Architectural Model:** Ephemeral, In-Memory, Zero-Database Architecture

---

## 1. Release Highlights

MediaForge v1.0.0 represents the first major production release of the universal media downloader and transcoding suite. Engineered from the ground up to respect user privacy and eliminate operational database overhead, MediaForge operates without persistent databases, user tracking, or account requirements.

### Supported Platforms
- **Web Portal:** Next.js 15 + TypeScript + Tailwind CSS (SSR & Standalone)
- **Windows Desktop:** Flutter x64 Windows Executable / Portable ZIP
- **macOS Desktop:** Flutter macOS App Bundle / DMG
- **Linux Desktop:** Flutter Linux x64 Bundle / Tarball
- **Android:** Flutter APK / AppBundle (ARM64 / x86_64)
- **iOS:** Flutter iOS Runner / IPA Bundle

---

## 2. Core Capabilities

### Media Downloader
- Direct inspection and streaming download of authorized public media URLs.
- Ephemeral chunked transfer protocol eliminating server heap bottlenecks.
- Comprehensive SSRF validation with multi-hop redirect verification.

### Universal Media Converter
- **Video:** MP4 (H.264/H.265/AV1), WebM (VP8/VP9), MKV, MOV, AVI.
- **Audio:** MP3 (libmp3lame), WAV (PCM), AAC, FLAC, M4A, OGG (Vorbis/Opus).
- **Images:** JPEG, PNG, WebP, AVIF with automatic EXIF/GPS privacy stripping.
- **Audio Extraction:** High-speed stream extraction from video containers.
- **Batch Processing:** Concurrent transcode queues with independent and collective cancellation.

## 5. Security Sign-off

- Strict URI filtering prevents SSRF and DNS rebinding attacks.
- Zero shell invocations: all processes use structured string arrays (`ProcessBuilder`).
- Codec whitelisting prevents command and flag injection (`^[a-zA-Z0-9_-]{1,32}$`).
- Decompression bomb caps enforced (16k dimension limit, 100M pixel cap).
- Strict HTTP security headers configured in web layer.
